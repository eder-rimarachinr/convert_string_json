What you can paste

          

            
Regular JSON

            
{"name":"John","age":30}

            
Escaped JSON string (logs, APIs, database columns)

            
"{\"name\":\"John\",\"age\":30}"

            
Double-escaped string

            
"\"{\\\"name\\\":\\\"John\\\"}\""

            
Single-quoted JavaScript string

            
'{"name":"John"}'

          

        


        

          
Your data stays exactly as it is

          

            Only whitespace changes. Large numbers such as 12345678901234567890,
            key order, duplicate keys and escape sequences are kept exactly as you wrote them,
            so the output is safe to paste back into your code.
          


          
Small mistakes, clearly flagged

          

            Trailing commas and missing closing brackets are fixed automatically, and the output
            tells you exactly what was changed. Anything else is reported with its line, column
            and the surrounding text so you can find it quickly.
          


          
Private by design

          

            Everything runs in your browser. Your JSON is never uploaded, logged or stored:
            it doesn't leave your device.
